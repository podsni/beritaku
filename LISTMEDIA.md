## 📡 Metode Pengambilan Feed

| Metode | Keterangan |
|--------|-----------|
| **RSS Langsung** | Feed XML/Atom diambil langsung dari server sumber media |
| **HTML Adapter** | Halaman HTML di-parse menggunakan Cheerio untuk ekstrak artikel |
| **Google News RSS** | Fallback RSS via `news.google.com/rss/search?q=site:domain.com` untuk media yang feed langsungnya tidak tersedia atau terblokir |

---

## 🗒️ Catatan Teknis

- Sumber yang **RSS-nya tidak aktif** atau terblokir saat dicek menggunakan fallback **Google News RSS**.
- Sumber dengan **proteksi bot** (status 403/429/503) didukung melalui browser fallback via `cloakbrowser` (opsional, instal terpisah).
- Sumber dari **OPML** (blog teknik populer dari Hacker News) di-load secara dinamis dari file `data/hn-popular-blogs-2025.opml` — ID mereka menggunakan prefix `blog-`.
- **Semua sumber** mendukung CSV fallback: jika fetch live gagal, artikel terakhir dari `data/news-cache.csv` atau `data/news-cache.sqlite` akan digunakan otomatis.
- Artikel gambar yang tidak tersedia di feed akan di-resolve saat `bun run refresh:news` dijalankan, menggunakan scraping `og:image` atau fallback Bing thumbnail.
